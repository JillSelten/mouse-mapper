Veelgestelde vragenFrequently asked questions

Werkt het met mijn muis?Does it work with my mouse?

Met bijna elke muis met zijknoppen (terug/vooruit) en een klikbaar scrollwiel. Sommige gaming-muizen sturen hun extra knoppen als toetsen; die worden niet herkend. Op 'Help en test' zie je live of je knop wordt gezien.With almost any mouse that has side buttons (back/forward) and a clickable scroll wheel. Some gaming mice send their extra buttons as keys; those are not detected. 'Help and test' shows live whether your button is seen.

Windows zegt “onbekende uitgever”. Is het veilig?Windows says “unknown publisher”. Is it safe?

De app is nog niet digitaal ondertekend. De volledige broncode staat openbaar op GitHub. Klik op Meer informatie → Toch uitvoeren.The app isn't code-signed yet. The full source code is public on GitHub. Click More info → Run anyway.

Hoe zet ik mijn knoppen terug naar normaal?How do I set my buttons back to normal?

Zet alle acties van een knop op 'Standaard', of zet 'Mapping aan' uit bij Instellingen.Set all actions of a button to 'Default', or turn off 'Mapping on' in Settings.
